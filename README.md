# ZENYS · Sistema de ventas

Tienda web de sillas gamer edición anime (GitHub Pages, sin servidor).

Estructura:
- `index/index.html`
- `Styles/Styles.css`
- `java/script.js` (catálogo, carrito y pedido por WhatsApp)
- `imagenes/` (fotos de las sillas y logo)

Para agregar una silla: copia su foto a `imagenes/` y añade un bloque en la lista `products` de `java/script.js`.
